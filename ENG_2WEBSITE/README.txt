TECHNICAL WRITING WEBSITE
=========================

Files:
- index.html: website structure and lesson content
- style.css: visual styling and responsive layout

How to use:
1. Keep index.html and style.css in the same folder.
2. Open index.html in a browser.
3. Replace [Your Full Name], [Your Course and Subject], [Your School / Institution], and your.email@example.com with your own details.
4. The sample graph values and examples are explicitly illustrative, not real research data.
5. The website content is limited to the seven requested lecture topics, plus the required Home, About Us, and Contact Info pages.

The website uses HTML, CSS, and inline SVG/CSS illustrations, so no separate image files are required.
